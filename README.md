# GENEVIEVE App Restore

Standalone static personal Restore PWA.

This repository is not a duplicate of the psychology, Life Companion, LISTENS or Health Navigator products and should remain separate.

## Platform

Static GitHub + Cloudflare Pages deployment. No server, database or environment variables are required by the current build.

## Current files

- `index.html` — complete application shell and client logic
- `manifest.webmanifest` — installable PWA metadata
- `service-worker.js` — offline support
- icon/logo assets

Ordinary repository cleanup must not merge this app into a clinical or command-centre repository merely because some wellbeing concepts overlap.
